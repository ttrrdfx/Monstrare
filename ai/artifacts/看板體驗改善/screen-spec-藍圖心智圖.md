# 畫面規格

## Metadata

- 功能：藍圖心智圖與看板即時同步
- 畫面：藍圖心智圖
- 狀態：mockup 已核准（Variant C，2026-09-05）

## 目的

讓使用者一眼理解 Epic → User Story → Task 的工作分解、目前進度與未完成區域，並可在大型藍圖中快速導覽。

## 版面配置

- 主要區域：由左到右的 Epic → User Story → Task 節點圖。
- 次要區域：同步狀態、節點階層圖例、完成度。
- 導覽：沿用頂部「看板／藍圖」分頁；藍圖內提供縮放、回到全景與收合。
- 動作：點擊 Task 開啟原有詳情 modal；點擊 Epic/User Story 切換收合狀態。

## 狀態

| 狀態 | 必要行為 | 空狀態／錯誤文案 | 驗證方式 |
|---|---|---|---|
| 預設 | 顯示三層節點、連線、進度與同步狀態 | — | 螢幕截圖 |
| 載入中 | 保留圖區尺寸，以節點骨架屏表示 | 「正在載入藍圖…」 | 螢幕截圖 |
| 空狀態 | 顯示建立 Epic/User Story 的說明 | 「尚無藍圖資料」 | 螢幕截圖 |
| 錯誤 | 保留上一份成功資料，顯示重試 | 「無法更新藍圖，請重試」 | 螢幕截圖 |
| 停用 | 縮放等工具降低對比且不可觸發 | — | 鍵盤與截圖 |
| 權限不足 | 可瀏覽與導覽，不顯示可寫操作 | 「唯讀檢視」 | 螢幕截圖 |
| 行動裝置版 | 改為聚焦單一 Epic 的水平畫布，用 44px 工具按鈕導覽 | 同桌面版 | 390px 螢幕截圖 |
| 同步中斷 | 保留現有藍圖，狀態指示器變為警示 | 「同步中斷，正在重新連線」 | 螢幕截圖 |

## 互動

| 動作 | 觸發條件 | 結果 | 失敗情境 |
|---|---|---|---|
| 平移 | 拖曳畫布空白區 | 移動視口，不改變資料 | 觸控與點擊手勢衝突時以移動閾值區分 |
| 縮放 | 滾輪、觸控手勢或 +/− | 以視口中心縮放 | 到達上下限時停用對應按鈕 |
| 回到全景 | 點擊全景按鈕 | 所有可見節點置中 | 無資料時停用 |
| 收合分支 | 點 Epic/User Story 的收合按鈕 | 後代節點與邊隱藏，進度保留 | 重新取得資料時保留同一頁籤內收合狀態 |
| 開啟任務 | 點擊 Task 或鍵盤 Enter | 開啟原有詳情 modal | Task 已刪除時顯示提示並重取資料 |

## 設計系統對照

- 用到的既有 design token：以 `tools/kanban/index.html` 的 `--paper`、`--surface`、`--surface-sunken`、`--ink*`、`--line*`、`--accent*`、`--good*`、`--warn*`、`--crit*`、`--shadow-card`、`--font-ui`、`--font-mono` 為現行實作來源。
- 用到的既有元件：頂部分頁、Card、Pill、Progress bar、Modal、Toast/Alert、Button。
- 本畫面新做的元件：Mind-map canvas、Hierarchy node、Connector、Canvas toolbar、Sync status。目前僅用於 mockup；選定後才依既有 token 實作並登記 inventory。

## 視覺驗收標準

- 桌面版在 1440×900 可同時辨識 Epic、User Story 與 Task 三層關係。
- 節點名稱最多顯示兩行，超出文字以省略號處理，完整值由 tooltip 或詳情提供。
- 層次由尺寸、字重與輔助文字建立，不只依賴顏色。
- 互動節點與工具皆有 default、hover、focus、disabled 與 loading 狀態。
- 所有間距使用 4px 倍數，字級使用 11/12/13/14/16/18/20/24 scale。
- 手機觸控按鈕至少 44×44px，關鍵文字不被截斷。
